ABOUT CYBERSHIELD

Understanding your network. Detecting suspicious activity.

CyberShield is a web-based Network Threat Detection System developed to monitor network traffic and identify selected suspicious activities. It provides a simple interface for reviewing captured packets, detected threats, and reports.

Built using Python, Flask, Scapy, and SQLite, the project demonstrates basic network monitoring and rule-based threat detection in an educational environment.
